01

安装 / 更新

点击脚本卡片中的按钮，浏览器会交给 Tampermonkey 打开官方安装确认界面。确认后完成安装或更新。

02

固定更新地址

脚本安装时写入固定的 HTTPS 更新地址。版本号递增并重新构建后，Tampermonkey 可以从同一地址检查新版本。

03

历史版本留档

每个版本首次构建时保存不可覆盖的历史快照。相同版本如果代码发生变化，构建会拒绝，避免版本号未更新。

i
关于安装状态与自动更新

网页无法读取 Tampermonkey 内部已安装脚本清单，因此不会虚报“已安装”。安装或更新需要在 Tampermonkey 确认一次。自动检查更新通过 GitHub Pages 提供，无需保持本地电脑或服务运行。
