# v1.5.0 / v1.5.1 / v1.5.2 智能画幅算法实验室
本目录是与正式播放器隔离的布局算法实验区。它不修改115真实索引、播放窗口、收藏夹或用户浏览器数据，也不依赖第三方运行时包。

## 本阶段目标

在正式播放器现有智能画幅算法之外，建立独立递归切分树候选算法并进行可复现对比。v1.5.0首次接入受控混合策略；v1.5.2将搜索参数优化为160次迭代×2次重启。v1.5.1因元数据行合并错误而废弃，不覆盖其历史快照。
## 算法参考与许可边界

- itsui/mosaicplayer：https://github.com/itsui/mosaicplayer ，GPL-3.0。只研究递归二叉切分树、布局树搜索和视频面积均衡的设计思路；本实验没有复制其源码、函数实现或代码片段。
- thangdevalone/meeting-grid-layout：https://github.com/thangdevalone/meeting-grid-layout ，MIT。参考其Area-Optimized Row Search的候选布局面积评分思路；本实验独立实现，没有引入该npm包。
- v1.4.0历史快照作为只读基准算法；正式播放器源代码不参与基准提取，避免实验基准随实现漂移。

## v1.5.2开发候选接入策略

- 4至12个视频窗口且宽高比类别分布较为多样（最大单一类别占比低于85%）时，评估递归切分树。
- 只有树候选综合评分优于基准且覆盖率下降不超过1个百分点时才采用，否则回退基准布局。
- 搜索参数为160次迭代×2次重启；保持视频原始比例，不裁切。
- 索引、取流、收藏夹、播放控制、锁定窗口和主副屏逻辑不变。
- 当前仅为开发候选，未发布至GitHub；真实115页面验收后置。
## 统一评价口径

| 指标 | 含义 | 方向 |
|---|---|---|
| 视频面积覆盖率 | 所有实际视频矩形面积之和 / 容器面积 | 越高越好 |
| 空白面积 | 1 - 视频面积覆盖率 | 越低越好 |
| 最大/最小窗口面积比 | 最大视频面积 / 最小视频面积 | 越接近1越均衡 |
| 面积变异系数 | 窗口面积标准差 / 平均面积 | 越低越均衡 |
| 裁切率 | 视频源宽高比偏离程度 | 必须为0 |
| 宽高比误差 | 输出矩形比例与源视频比例的相对误差 | 接近0 |
| 重叠/越界 | 视频矩形之间重叠或超出容器 | 必须为0 |
| 计算耗时 | 单次布局计算时间 | 越低越好 |

当前阶段严格保持视频原始宽高比，不允许裁切；布局算法只负责给出矩形坐标，不负责索引、取流、播放控制或收藏逻辑。

## 运行

在仓库根目录执行：

- 快速对比：node experiments/layout-lab-v1.5.0/run-benchmark.js --quick
- 完整基准：node experiments/layout-lab-v1.5.0/run-benchmark.js
- 实验回归：node --test tests/layout-lab.test.js
- 完整仓库检查：npm run check

报告和逐场景数据写入本目录的 output/REPORT.md 与 output/results.json。

## 进入正式播放器的门槛

1. 覆盖率相较当前算法有稳定提升，而不是只在少数比例组合中胜出。
2. 最大/最小窗口面积比和面积变异系数不能出现明显退化。
3. 裁切率必须为0，宽高比误差接近0。
4. 不能出现窗口重叠、越界、丢失或重复。
5. 计算耗时必须适合浏览器主线程；若需要异步搜索，必须能立即给出可用初始布局并在后台细化。
6. 只替换智能画幅计算层，保留现有索引、加载、播放、锁定、收藏、主副屏和窗口交互。

实验结果不自动构成版本发布或替换决定。
