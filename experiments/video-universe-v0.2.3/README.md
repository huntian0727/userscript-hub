# 视频宇宙 v0.2.3 — 可点击的视频卫星

交付编号 VU-023-01。以已公开的 v0.2.2 为基线，在 HOME 电脑独立分支 experiment/video-universe-moons-v0.2.3 开发。视频卫星只是已扫描样本的可视化，并不是新建目录，也不会写入115账号或旧播放器存储。

## 新交互

- 点击目录星球后，聚焦中心周围除了子/同级目录星球，也出现动态环绕的发光视频卫星，最多显示 9 个采样视频，随视角旋转具有三维透视。
- 点击视频卫星选中对应文件，在右侧预览显示文件名、大小、115官方播放入口。演示卫星只可查看样本，不可真实播放；无有效提取码禁用原生播放。
- 隐藏卫星/显示卫星只影响画面，不改变已扫描数据，也不隐藏右侧九格样本。
- 返回上级星球顺着目录父子关系回退；空白处或回到全景恢复整个星图。拖动不触发选片，保留 v0.2.2 的聚焦和分页。
- 只使用原有 GET 目录请求；样本最多 16 条/目录，卫星最多 9 颗，不追加任何播放源拉取、不进行文件删除或索引迁移。

## 验证

- node --check userscripts/115-video-universe.user.js
- node --test tests/115-video-universe.test.js
- node experiments/video-universe-v0.2.3/run-moons-smoke.js：Chrome WebGL 模式验证视频卫星、点击预览、显隐、返回父星球和拖动/空白点击
- 环境变量 UNIVERSE_FORCE_FALLBACK=1 下运行同一脚本：Chrome Canvas 兼容模式
- npm run check：全仓库及不可变版本快照校验

真实115目录扫描和原生播放的账号登录场景仍待独立验收。

## 保护和回滚

不得覆盖视频宇宙 v0.1.0 / v0.2.0 / v0.2.1 / v0.2.2 或稳定多宫格播放器的历史快照，发布仅更新独立脚本 115-video-universe 的版本。完整可安装归档 history/115-video-universe/0.2.3.user.js。发布提交与实际 Pages 版本单独核验。
