# 115 多宫格播放器 2.0 — 快速交付实施方案

状态：按 2.0 最小完整可用版本（MVP）发布。
开发分支：`develop/random-playback-v2.0`
基线：已发布 v1.9.1；保持独立更新通道。
目标版本：v2.0.0。

## 一、2.0 必须交付

### P0 — 核心随机探索与播放
- 统一配置入口：文件夹模式/全盘模式；文件夹可多选，默认递归子文件夹；全盘模式忽略并禁用文件夹选择。
- 筛选：文件名关键词 OR 匹配、排除词、最小/最大文件大小。
- 随机：按 115 实际匹配视频数量自然加权；仅按 115 文件 ID 去重；不做内容哈希。
- 轮次：每轮尽量不重复；允许用户手动开启新一轮。
- 播放：首个可播放视频就绪后启动；支持单格换片、全部换一批；锁定格不替换；播放失败自动跳过。
- 不依赖旧目录索引或扫描即可播放；旧索引写入、旧扫描入口及其播放前置依赖在 2.0 中移除。
- v1.x 旧索引数据库仅保留只读收藏兼容查询；不得创建、更新或删除旧扫描记录，不删除用户现有数据。

### P1 — 配置与恢复
- 保存多个方案，保存来源范围、文件夹 ID/路径、筛选条件和排序。
- 自 v2.0.12 起，选择方案立即载入条件，沿用新建和使用后置顶。保存只更新选中方案的条件，另存用新名称创建方案，删除只移除所选记录。手动排序按钮由这三个操作取代，备份仍保留方案顺序。
- 2.0 提供本地 JSON 配置导出/导入，包含收藏夹、收藏/排除、方案、播放器设置和必要的轮次状态；导入前校验格式、版本和数量限制，支持合并/覆盖。
- 用户可将导出的 JSON 手动上传到 115 根目录专用目录：`拉面多宫格播放器/配置备份`；缓存丢失时手动下载后导入。
- **2.0 不提供自动上传、云端回读校验或当前/上一份自动轮换**：目前没有可验证、可授权使用的公开上传接口；这些能力列入 2.1，禁止猜测或调用未公开接口。
- 备份只存配置，不存 Cookie、Token、账号凭据、播放 URL 或视频内容。

## 二、2.0 发布验收
- 自动化：脚本语法、核心随机/播放器行为、旧版并行与历史快照保护、完整项目检查、安装中心构建通过。
- 发布：v2.0 使用独立脚本/更新地址；旧版 v0.12.4、v1.9.1 等历史发布保持不变；版本号、安装入口、更新说明和回滚地址核对。
- 真实 115 环境的文件夹/全盘/筛选/播放/换片/锁定/失败跳过/新轮次/方案/备份恢复，由用户安装后自行验收；助手不登录、不扫码、不执行真实账号测试，也不以此阻塞发布。
- 真实账号验收结果由用户反馈后记录；未反馈前不得宣称已完成真实 115 验证。

## 四、明确放到 2.1 的内容
- 收藏夹作为随机来源（现有收藏能力保持原样）。
- 自动上传至 115 根目录、当前+上一份自动轮换、云端回读校验；前提是取得可验证的官方公开 API/授权。
- 自动定时备份、跨账号迁移、多版本历史。
- 大规模压力测试、长时间稳定性测试、极端网络/账号异常的完整组合测试。
- 过度细分的内部函数行为测试、重复性的源码特征断言和非关键重构。
- 高级播放统计、使用分析、复杂诊断面板、额外布局/动画和 UI 微调。
- 任何不影响上述 P0/P1 的性能微优化和代码洁净度专项。

若发现会导致数据丢失、错误覆盖锁定视频、重复播放规则失效、无法启动/换片/恢复本地 JSON 配置的真实缺陷，仍必须在 2.0 修复。

## 五、实现约束与保护
- 115 文件 ID 是跨来源去重的唯一依据；禁止内容哈希。
- 文件夹浏览按需分页，不构建本地目录索引。
- 旧版历史发布快照不可修改；新版本独立更新通道。
- 不删除用户视频、不改动无关 115 内容、不清空旧 IndexedDB 数据。
- 旧索引只读兼容代码仅用于补全历史收藏信息，不得用于随机候选、播放、扫描或写入。
- 不调用未公开/未授权的 115 上传接口；不保留无用的上传域名权限声明。
- 不把任何凭据或播放数据写入备份。
- 用户已明确授权 2.0 独立发布；发布时只更新 2.0 入口，不覆盖任何旧版本。


## 2026-11-08 单关键词全盘搜索性能修复
全盘仅一个包含关键词时，优先从 115 搜索匹配结果抽样，并继续本地验证关键词、排除词、文件大小与本轮去重；搜索结果超过接口上限或初始化搜索失败时回退全盘随机过滤。多关键词 OR、文件夹来源沿用原有全量随机逻辑，避免改变覆盖范围和加权语义。搜索结果在本轮中增长到上限时中止该轮并提示重新开始，避免静默截断。真实 115 搜索覆盖与性能仍需用户验证。
