# v1.0.0 开发计划

## 产品定位

115视频随机探索工具。播放器是基础，视频发现、筛选、收藏和连续探索是核心体验。

## 版本原则

- 开发基于v0.12.4，旧版0.x保持可回滚。
- v1.0.0开发在`develop/v1.0.0`分支进行，验收前不更新main和线上安装入口。
- 不清空、不重建用户IndexedDB；数据结构升级必须可迁移、可回退。
- 每个阶段都要有自动化测试和真实115页面验收。

## 第一阶段：现有体验打磨

1. 统一锁定、单格换片、全部换片、新一轮、自动换片、同目录模式的行为。
2. 完善播放失败重试、自动跳过和登录验证阻断处理。
3. 验证智能画幅在横屏、竖屏、混合比例及动态换片时的布局。
4. 优化索引状态和后台扫描提示，避免遮挡播放区域。
5. 回归2/4/6/9/12宫格、主副屏、退出、收藏、排除、文件夹打开和删除操作。

## 第二阶段：自定义收藏夹

1. 保留旧收藏字段和默认收藏入口。
2. 增加自定义收藏夹与视频-收藏夹关系。
3. 旧收藏无损迁移到默认收藏夹。
4. 同一视频可属于多个收藏夹；删除收藏夹只删除关系，不删除115文件。
5. 收藏夹支持筛选、随机抽取和多宫格播放。
6. 新旧备份兼容，迁移失败时保留原数据。

## 暂不纳入

AI内容识别、云端索引、大规模架构重写、复杂统计分析。

## 第一轮源码审查发现

v0.12.4的`createCell`中，`loadedmetadata`事件监听器存在重复注册，造成相同进度刷新和布局重排重复执行。v1.0.0首个清理项移除重复监听，并增加回归断言；不改变播放行为。
