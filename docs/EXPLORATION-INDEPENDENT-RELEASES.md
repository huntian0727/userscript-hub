# 115 探索类独立脚本发行规范

适用范围：视频宇宙、兴趣引力场、视频盲盒、视频大逃杀、探索雷达、时光穿梭等今后所有探索性试点。

## 核心约定（自 v0.1.0 起）

1. 每个探索玩法独立建档：拥有自己的脚本 ID、userscripts/<id>.user.js、Tampermonkey 名称和 namespace、独立版本序列、专属更新 URL 与安装链接，不复用/覆盖已有播放器通道。
2. 按独立实验发布：首个实验版从 v0.1.0 起；后续迭代只提升该实验的版本，不通过修改稳定版或全盘探索版来发版。
3. 独立的数据边界：不清理、不迁移、不写入旧插件 IndexedDB、收藏、索引和配置。共享数据必须设计显式只读接口，不同账号不混杂。
4. 保留旧安装链接和历史版本：原稳定版 115-multiview-indexed v0.12.4、全盘探索独立版 115-multiview-full-disk v1.7.0 不得被探索脚本自动升级/覆盖。每版发布包写入新的 history/<id>/<version>.user.js，不改写历史快照。
5. 隔离开发/验收：通过独立分支或工作树实现，执行语法、纯逻辑、浏览器模拟、静态构建和上线验收；不能把模拟数据冒充真实扫描结果。
6. 试点优先：先提供能体验的交互，少做无关基础设施。真实 API 只读访问必须有明确范围、暂停、错误提示和数量口径；部分扫描不能宣称全盘完整结果。
7. 发布前核验：registry 允许项、独立版本/更新/下载链接、历史 SHA、线上 HTTP 状态、功能入口和旧版可用性。普通错误自行修复，未发布就标候选。
